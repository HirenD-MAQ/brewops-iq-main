Before the session · one-time setup (5 min)

Prerequisites

Do this before you arrive. A missing or wrong login is the single thing that'll cost you time on the day — don't sort it out during the race.

✓

Node.js 20+

node --version # want v20 or newer
✓

Install the GitHub Copilot CLI

npm install -g @github/copilot

On Windows PowerShell, run this once so the CLI is allowed to run:

Set-ExecutionPolicy -Scope CurrentUser RemoteSigned -Force

Then check copilot --version. If it's "not recognized," reopen your terminal.

✓

Sign in — with the RIGHT account

copilot

Sign in with the GitHub account that has your Copilot license (your work account) — not a personal one.

✓

Confirm it works

copilot -p "hello"

You should see an AI Credits … line at the end. No line = you're not signed in with a Copilot-enabled account.

The flow · six steps

What you actually do

1

Fork the repo

On the repo page, click Fork. That's your private copy of the arena — no invite needed.

2

Clone your fork & install

git clone https://github.com/<you>/brewops-iq && cd brewops-iq && npm install
3

Build your harness — this is the whole competition

The agent has no memory between runs; your files are its brain. Fair game: .github/copilot-instructions.md and AGENTS.md, a repo-map, distilled per-module briefs, skills (copilot skill), a plan/progress file you update between runs. How you engineer this is the challenge.

SPEC.md is the only source of truth. The files under src/legacy/ and docs/RETRO.md describe the old register software — their rules contradict SPEC.md and are traps. Your harness has to name them and steer clear.

4

Run the agent — as many runs as your strategy needs

The wrapper runs Copilot with a fixed prompt against your harness files and records each run's cost to COST.txt automatically. You steer between runs by editing your harness files — e.g. scope run 2 to "audit module only".

node agent-run.mjs --model gpt-5-mini

gpt-5-mini is just an example — use any model you like with --model <name>.

5

Iterate — and stay lean

Three focused runs often beat one mega-run that fails and retries. Each run adds to your cumulative COST.txt. Switch models freely — cheapest model your harness can carry through the gate wins. The agent must never write or run tests.

6

Commit & push — then re-push to climb

git add src COST.txt && git commit -m submit && git push

At each checkpoint the leaderboard updates with your score + cost. Refine, re-run, push again. Pencils down = your last push.

How cost is measured

Run your agent through the wrapper — cost tracks itself

The Copilot CLI prints the exact credits it spent after every run. agent-run.mjs reads that number and adds each run's credits to COST.txt for you — nothing to read off a screen.

Pick your model with --model <name>. To see your available models, run copilot then /model.

COST.txt — the whole file
5.20
One number on the first line — your total AI credits across every run, not just your last. Nothing else in the file. (1 credit = $0.01; the judge reads the first number it finds.)

Under-reporting is a DQ. Top scorers screen-share their credit total before prizes.

Watch out — the repo has traps on purpose

Files that will mislead a naive agent

These files exist to teach the value of guardrails. Your harness should tell the agent to ignore them.

src/legacy/pricingV0.ts

The old FieldPos register pricing. Uses banker's rounding, cumulative offer stacking, an automatic tier discount before offers, exclusive validTo, and at most one bundle per ticket. Every one of those rules contradicts SPEC.md. A cheap model asked to "look around first" will copy the shape and lose the tests.

src/legacy/oldTiers.ts

A "tier matrix" claiming silver = 5% off, gold = 10% off, plus a "regional seasonal uplift". None of this exists in SPEC.md. Tier only affects offer eligibility.

docs/RETRO.md

Retrospective notes. Says finance "insists on banker's rounding", offers "stack cumulatively", dayOfWeek was cancelled, eligibleTiers is a wishlist, and threshold offers qualify on the gross subtotal. All wrong vs. SPEC.md. A conversational summary of these notes will burn your credits.

How you're scored

Qualify, then cheapest wins

Step 1 · qualify

The gate

Your modules must pass 100% of the core hidden tests — across all three parts. A good harness gets there; a bare one-shot doesn't.

Step 2 · win

Champion

Lowest total credit cost among everyone who qualifies. Model choice is your biggest lever. Ties break on the bonus edge-case tests, then earliest to qualify.

SPEC.md is the single source of truth. Everything else — README, RULES, this guide, even the retro doc — exists to help you read that spec correctly. Good luck.
